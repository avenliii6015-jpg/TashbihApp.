# آموزش تشبیه

اپلیکیشن آموزشی فارسی با Jetpack Compose؛ شامل آموزش، نمونه‌ها، آزمون چهارگزینه‌ای، بازی تشخیص ارکان و ذخیرهٔ امتیاز و تعداد پاسخ‌ها روی دستگاه.

## ساخت APK با GitHub
1. یک مخزن جدید در GitHub بساز.
2. تمام فایل‌ها و پوشه‌های این پروژه را در ریشهٔ مخزن بارگذاری کن.
3. از بخش **Actions** اجرای گردش‌کار **Build Android APK** را باز کن.
4. پس از موفقیت، از بخش **Artifacts** فایل `Amuzesh-Tashbih-debug-apk` را دریافت کن.
5. فایل `app-debug.apk` داخل ZIP قرار دارد.

## ساختار آیکون
آیکون PNG در پنج اندازهٔ استاندارد Android و در پوشه‌های `mipmap-*` قرار گرفته است.
